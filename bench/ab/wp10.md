`python3 -m engine.v15_pipeline ...` with the **system** `/usr/bin/python3`
instead of the project's `venv/bin/python3` (`docs/testing.md`'s documented
entrypoint). The system interpreter has no `faster-whisper`, so the voice
round-trip ASR check silently degraded to `"round-trip ASR did not run on

real render (which *did* have a working ASR check) before trusting the
verdict. Fix: reverted the incidental `beat_*.timing.json` changes and
deleted the incidental `beat_*.voice.json` files (`git checkout --`, same
"cache regeneration is not part of the diff" precedent WP9 set), then
re-ran the full render with `venv/bin/python3` activated. The report below
is from the corrected (venv) run only — the first attempt's output was
discarded, not used for the verdict.
