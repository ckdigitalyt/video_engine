- Known: `research/phase2/llm_compare.py` calls the removed private `_text_gemini/_vision_*` helpers (one-off Phase 2 benchmark script; not part of the pipeline).

## WP2 — Fail-closed QA
- Verdicts are now `PASS` / `HOLD` / `FAIL` (`v15_gate.verdict_of`): `FAIL` = a check ran and found a confirmed defect (`critical`), `HOLD` = a check could not run (`unverified`) or found a soft problem. Exit code of `v15_pipeline` and `v15_batch` is still "0 only on PASS".
- New gate check `plates`: plate QA must have RUN (`checked:true`; "plate QA did not run" = HOLD, also for `--no-plate-qa`), no plate may still fail it after regeneration (FAIL), regenerated plates must be re-checked (else HOLD), and the gate itself OCR-reads every plate used for provider stamps/domains, independent of the pipeline's QA path (a stamped plate = FAIL even if the vision call passed or was skipped).
- OCR pre-filter (`v15_plates.ocr_watermark`, tesseract CLI, no new dependency): reads only the bottom 10 % / top 7 % strips, hits only on known stamp tokens or a domain-like string (full-plate OCR of textured art is noise). Runs inside `plate_qa` before the vision call at no LLM cost, cached beside the plate as `.ocr.json`; hits fail the plate and trigger the existing regeneration round. Fixture: the Phase 2 blackhole "pollinations.ai" plate (`illustrated_engine/tests/fixtures/`).
- Judge: ONE critical frame fails (`text_garbled`, `text_unreadable`, `watermark`, `overlap`; V15 needed two). New issue codes `watermark`/`overlap` in the prompt and `llm/schemas/final_judge.json`. `empty_or_flat`/`subject_unrecognizable`/`too_dark` keep the two-frame rule (HOLD).
- New gate check `caption_safe` (ink bbox of every caption overlay inside the safe frame and clear of the right UI rail) and a right-rail rule in `text_bounds` (DESIGN §7: x>930 below y=760).
- Not done, deliberately: the file rename `v15_gate.py → v16_gate.py` / `v16_plates.py` (no reason to churn imports before the v16 pipeline exists); DESIGN §7's top-220 / bottom-1440 insets and the 84 px caption-size rule (they move with the layout in WP6/WP5); judge frame cadence 1 s/2 s (S11, later).
- No fallback or retry path was removed or narrowed: the plate regeneration round, provider chain and judge chain are untouched (the gate is stricter, not the recovery).
- Consequence to expect: V15's headline/label boxes are right-aligned to x≈1010 at y≈800, so every V15 render now HOLDs on `text_bounds` (right rail) until the WP6/WP7 layout changes.

## WP3 — Voice layer
- New `illustrated_engine/engine/voice/` (DESIGN §5): `synthesize()` (one voice, per-sentence synthesis joined with designed gaps hook 80 / normal 150 / before-payoff 300 ms, speed multiplier per role within 0.95–1.08, peak scale-down instead of clipping), `synthesize_video()` (V15: one wav per beat, ONE voice per video; if the chosen voice fails part-way every beat wav is discarded and the whole script is redone with the next voice in `fallback`; switch recorded in `voice.switches`; cached beats are reused only when voice+config+text match, so voices are never mixed).
- Providers: `kokoro` (local, fp32, `am_michael`; the channel voice per owner decision) and `fish` (with-timestamp endpoint, native word times). Fish is **disabled by default**: it raises `VoiceUnavailable` unless `FISH_PLAN=paid` AND the voice entry has `commercial_ok: true` (and never accepts `*-free`). `configs/voice.yaml` is new; legacy `configs/voices.yaml` (mission_run.py / `src/`) is untouched.
- Timing: faster-whisper `base.en` word timestamps sequence-aligned to the *script* words (script keeps the spelling; unheard words are interpolated). `v15_timing.silence_v1` is kept as the offline last resort (load-bearing fallback) and still owns the per-beat timing cache (`beat_timing`; cache key no longer includes the method name, so old `.timing.json` are recomputed once). `faster-whisper==1.2.1` added to requirements/venv (local, MIT, models already in the HF cache; no credentials).
- Lexicon `brand/ink_ember/lexicon.yaml` (15 entries; `phonemes` for Kokoro, lowercase `respell` for the retry, `heard_as` ASR spellings of plausible reads). "Tyrannosaurus" read as "terenasaurus" at sentence start without it.
- Round-trip QA (`voice/qa.py`): normalised WER ≤ 0.03 (spelling variants and digits/number words normalised) AND every hard token (lexicon words, numbers, capitalised mid-sentence names, long capitalised openers) must be heard. Failing sentences are re-synthesised ONCE (respelling, 0.95× speed), then HOLD. ASR unavailable = HOLD, never a pass.
- V15: `v15_pipeline` calls `synthesize_video`, records `report["voice"]`; new gate check `voice` (QA not run / failed / voice not cleared for commercial use → HOLD).
- `engine/tts.py` is now a thin `tts_beat` adapter (V14 still uses it). **Removed:** the Fish-free-tier-pinned path (`_get_provider`, `_ensure_env_key`, `tts_story`, `ffprobe_duration`) — the free tier is non-commercial and the owner disabled Fish (round-3 decision 2). Fish is not a silent fallback anymore; Kokoro is. Old one-off scripts updated (`bench/tts_ab.py`, `research/phase2/fish_timestamps.py`, `research/phase3/voice_samples.py`) or marked broken (`research/phase2/fish_check.py`).
- **Flag for owner (DESIGN §15.3 item 3):** V15's documented "Fish only, no fallback, STOP" policy is replaced by Kokoro-first with a whole-video fallback chain; the fallback chain currently contains only Kokoro. No fallback/retry path that existed for an external service was narrowed.

## WP4 — Story engine (S1-S4)
- `llm/prompts.py` + `llm/prompts/<stage>.md` (versioned; `prompt_version` feeds the adapter cache key) and `llm/schemas/{research_extract,script_write,script_critic,fact_check,metadata_pack}.json`. The five stages already existed in `configs/llm.yaml`; no config change.
- `illustrated_engine/engine/v16_research.py` (S1): `build_facts` (one `research_extract` call over already-fetched source text) drops every claim whose quote is not found in its source (whitespace/case/curly-quote tolerant) or whose claim text adds a number the quote lacks; fewer than 3 survivors = `ResearchHold`. `from_curated` reads bench packs (only `verified:true` claims are usable; a source-check `correction` replaces the wording; unknown nuance labels map to CONTESTED). `numbers_in` reads digits and spelled numbers ("sixty-five", "eighty million").
- `illustrated_engine/engine/v16_script.py` (S2-S4): pure-code checks (75-140 words, hook <=12 words and not a bare question, roles, no goodbye/CTA, narration digits voice-safe, every sentence cites a usable fact, narration numbers appear in the CITED facts, on-screen numbers are spoken, post-TTS 30-60 s gate, title rules, batch How/Why/What share, hashtags) plus `write_story`: script_write -> [rewrite on code errors] -> script_critic (mean >=4.0, none <3) -> one rewrite -> fact_check (one rewrite) -> metadata_pack (one retry on rule failure). Always returns PASS or HOLD with reasons; an `LLMUnavailable` is a HOLD carrying `retry_at`. Typical run 4 calls (2 Opus, 2 Sonnet); worst case 8.
- Tests: `illustrated_engine/tests/test_wp4_story.py`, 29 tests, fake `ask`, no network.
- Lexicon: added `kulik` (ASR-checked, not listened to).
- Deviations from DESIGN §9.4: the title-honesty check is code-only (cited `title_fact_ids` must exist, title numbers must be in those facts, trope ban) — no extra LLM call. Loop coherence is scored by the critic; code only rejects goodbyes/questions as last line (a lexical overlap check fails DESIGN's own example).
- No fallback or retry path was removed or narrowed.
